# Events System v2

The Events system treats `/events/` as the live expression of the Segun Samuel intellectual ecosystem.

## Landing page
- Featured event architecture
- Event discovery with search and type filters
- Programme-development status rather than invented dates
- Event Promise
- Event memory / archive pathway

## Detail page
- Event hero + approved placeholder system
- Event intelligence bar
- Overview
- Why Attend
- Highlights
- Who Should Attend
- Registration/enquiry state
- FAQ
- Continue the Work ecosystem connections
- Share actions

No dates, venues, ticket prices or speakers are invented where the current source material does not establish them.
