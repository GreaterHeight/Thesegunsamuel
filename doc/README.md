# /doc/IMAGE-PROMPTS.md

`IMAGE-PROMPTS.md` is the single master image-prompt file.

## How to use it

Copy **one individual finished prompt** into Nano Banana Pro. Do not execute the entire file.

## Source merge

The master contains:
- the current `SegunSamuel-IMAGE-PROMPTS-UPDATED.md` register as the canonical production layer;
- the complete `D-IMG-PROMPTS.md` source retained verbatim in the legacy archive.

When a filename appears in both, use the canonical block.

## Permanent human-subject rule

The final prompt copied into Nano Banana Pro must itself contain the intended human demographic composition. Do not rely on this README or another section of the master file to supply missing subject information.

## Naming

The canonical file is intentionally named:

`IMAGE-PROMPTS.md`

Do not create another competing master prompt filename for future updates.
