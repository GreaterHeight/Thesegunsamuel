# Programme 4 — Application / Consulting / Speaking System v1

## Built
### Applications
- Rebuilt `/application/` as the application-system landing page.
- Existing 21 application detail pages remain intact.
- All 21 detail pages are now first-class canonical application entities.
- Each application is explicitly `part_of` Applications / Projects.
- Application assets are searchable in Global Search.

### Consulting
- Added `/consulting/`.
- Defines the advisory architecture across strategy, systems, intelligence/foresight, AI/data, leadership/power and institution building.
- Includes an engagement method and contact pathway.

### Speaking
- Added `/speaking/`.
- Defines signature speaking themes derived from the existing ecosystem territory.
- Defines four engagement formats: keynote, conversation, workshop and executive session.
- Includes invitation/contact pathway.

### Ecosystem integration
- Applications / Projects now explicitly connects to Consulting and Speaking at the platform architecture level.
- Consulting and Speaking canonical service entities now have public routes.
- Discovery Intelligence is enabled on the 21 application detail pages and the two new service pages.

## Boundary
This is the front-end/system architecture phase. No payment, CRM, calendar, proposal automation, or external enquiry backend has been invented or connected here.

## Next implementation layer
The next stage for this programme is Engagement Intake & Routing:
- enquiry classification;
- engagement type;
- organisation/context;
- problem statement;
- desired outcome;
- preferred engagement format;
- route to appropriate service/application;
- confirmation and follow-up.
