# v3.13.5 — Global Shell Integration

## Correction

The v3.13.2–v3.13.4 pillar landing pages used a temporary standalone navigation
shell and did not include the site's approved global footer. This caused the
pillar pages to look unlike the rest of the website.

v3.13.5 replaces that temporary shell on:

- `/learn/`
- `/think/`
- `/apply/`
- `/listen/`

with the same global header/footer architecture used by the established
Courses experience.

## Preserved

- Pillar page content and card mapping
- Search/filter behavior
- Canonical entity routes
- Knowledge Graph data
- Existing Courses, Course Detail, Search and Entity Experience pages

## Intention

These four pages should now behave as first-class pages in the existing
SegunSamuel website, not as detached mini-sites.
