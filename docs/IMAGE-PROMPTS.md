# IMAGE-PROMPTS.md — SegunSamuel.com

## Purpose

This is the working image-generation prompt library for the SegunSamuel website.

Use it with Nano Banana Pro or another high-end image model. Every generated asset must be saved using the **exact filename** specified in the prompt. The website should continue to work when an image is missing by showing its designed gradient/architectural placeholder.

Do not bake website copy, prices, buttons, labels, course metadata, logos or UI text into generated images. Those belong in HTML.

---

## Global visual direction

Append this direction to every prompt unless a section explicitly overrides it:

> Ultra-realistic cinematic editorial photography, premium magazine quality, 8K detail, natural cinematic lighting, sophisticated professional colour grading using the SegunSamuel palette: deep forest green #0D3D28, dark forest #003020, warm cream #FDFAF4, mint #EAF5F1, restrained crimson #8C0D0C and selective gold #C9A64B. Rich but natural contrast, no artificial plastic skin, no oversharpening, no excessive HDR, no pure black unless specifically requested, shadows leaning toward deep green. Medium-format camera character, 85mm editorial lens look where appropriate, shallow depth of field for portraits, realistic materials and believable environments. Premium, intelligent, strategic, contemporary, emotionally restrained. No watermark, no random text, no fake logos.

### Diversity options

**Mixed** — a naturally diverse group of African, European and Asian professionals.

**All Black** — a group of distinguished Black African professionals.

**All White** — a group of distinguished White European professionals.

When the image represents Segun Samuel personally, use the supplied reference photograph where available rather than inventing a different identity.

# Placeholder implementation rule

Every image slot should use the architectural frame pattern:

```html
<div class="arch-frame">
  <img src="/images/example.jpg" alt="">
</div>
```

The CSS must keep the image contained as:

```css
.arch-frame img{
  width:100%;
  height:100%;
  object-fit:cover;
  display:block;
}
```

If the image does not exist, the frame's gradient background remains visible.

Before accepting any generated image:

- Correct filename
- Correct aspect ratio
- Subject survives mobile crop
- No random text

- No invented logo

- Appropriate diversity option
- Industry-appropriate setting
