### Canonical prices
The legacy `courses.js` catalogue was carrying older prices than the current course pages. It has been synchronized to the current catalogue.

### Cart architecture
`commerce.js` is the primary cart engine and uses one storage key:

`segun_cart`

The legacy `courses.js` file is now a compatibility layer. It no longer attaches a second `.add-to-cart` handler, preventing duplicate additions where both scripts are loaded.

### Detail-page IDs
The Advanced Data Analytics & Power BI and Systems & Strategic Architecture detail pages now use the same IDs as the Courses catalogue.

### Checkout
Checkout display now accepts the canonical cart `title` field while retaining compatibility with legacy `name`.
