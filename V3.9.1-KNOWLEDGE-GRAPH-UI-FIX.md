# v3.9.1 — Knowledge Graph UI Fix

Confirmed defect from live v3.9:
The canonical graph data uses `title`, while `explore/index.html` attempted to render `label`, causing every node title to display as `undefined`.

Fix:
- Search now indexes title, type, tags and description.
- Cards render `title`.
- Nodes without a canonical route no longer produce broken OPEN links.
- No graph data, taxonomy or relationship semantics changed.

Baseline preserved: v3.9 Knowledge Graph Integration.
