Project Brief

Produce evidence of capability.

Produce a signal register, relationship map, pattern interpretation and strategic implications.

01 — Define the problem

State the real-world problem, context, stakeholders, constraints and desired outcome.

02 — Apply the framework

Use the relevant SegunSamuel framework to structure observation, interpretation and design.

03 — Build the artefact

Create the report, system, model, dashboard, architecture, workflow or operating plan.

04 — Test and review

Challenge assumptions, gather feedback and document what changed.

05 — Present evidence

Package the result as a portfolio-quality demonstration of capability.

Evidence Standard

Problem → Method → Artefact → Reflection

The goal is not to complete an exercise for its own sake. The goal is to create evidence that the learner can think and act.
