# v3.3 — Courses Experience Reconstruction

This full build is based on v3.2 and includes the course-detail consistency work requested before the next live QA cycle.

## Course detail architecture
Each course now uses the same sequence after Curriculum: Hosted By → Requirements → Testimonial → FAQ → Applied Case → Knowledge Graph → Related Knowledge → Enrollment.

## Knowledge Graph vs Related Knowledge
Knowledge Graph = structural relationship layer showing where the course sits in the wider capability system.

Related Knowledge = curated navigation layer pointing learners to Frameworks, Ideas & Articles, Masterclasses, Learning Paths, Case Studies, Application, Podcast and Related Courses.

## Automatic media slots
- Instructor: `assets/images/instructors/segun-samuel.jpg`
- Testimonial image: `assets/images/testimonials/<course-slug>.jpg`
- Testimonial video: `assets/videos/testimonials/<course-slug>.mp4`

If these files are not present, graceful placeholders are shown. If supplied later using the expected path, the page automatically displays them without changing the HTML structure.
