Curriculum Architecture

Seven months of progressive capability.

This is the course architecture; cohort-specific scheduling can be finalized before enrolment.

Module 01 — Data & Analytical Thinking

Data fundamentals, analytical questions, data quality, business context and the discipline of moving from information to insight.

Module 02 — SQL Foundations

Queries, filtering, sorting, aggregation, joins, subqueries and practical extraction.

Module 03 — Advanced SQL & Data Preparation

Transformation, reusable logic and practical preparation of datasets.

Module 04 — Power BI Foundations

Data loading, report construction, analytical navigation and the Power BI workflow.

Module 05 — Data Modelling & DAX

Relationships, modelling principles, measures and analytical expressions.

Module 06 — Dashboard & BI Design

Visual communication, KPI design, dashboard structure and decision-oriented reporting.

Module 07 — Capstone & Portfolio

An end-to-end project combining SQL, analytics, Power BI and business interpretation.
