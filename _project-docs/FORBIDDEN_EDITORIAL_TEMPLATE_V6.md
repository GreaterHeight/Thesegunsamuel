Implemented the supplied reference-style editorial detail architecture across all 10 Forbidden detail pages.

## Structure

- Global Segun Samuel header/navigation retained.
- Cinematic dark editorial hero with placeholder + Segun badge.
- Category/title/deck/date/author/read-time metadata.
- Audio strip.
- Main editorial reading column.
- In This Dispatch rail generated from section markers.
- Tags and share controls.

- Existing global footer retained.

## Important

The template does not introduce an age-restriction gate. It treats "Forbidden" as the publication/editorial identity requested by the project.

No existing files outside the Forbidden detail implementation were deleted.
