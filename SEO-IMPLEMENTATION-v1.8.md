# v1.8 — Global SEO + Discoverability Foundation

Implemented across 200 HTML pages.

- Unique/preserved page titles
- Meta descriptions
- Canonical URLs
- Robots directives
- Open Graph metadata
- Twitter card metadata
- JSON-LD WebSite/WebPage and contextual Course/Article/Book schemas
- BreadcrumbList structured data
- robots.txt
- sitemap.xml (196 public URLs)
- llms.txt
- llms-full.txt

Transactional/private routes are excluded from the public sitemap and marked noindex/follow.

## Deployment
Upload the package contents to the root of the GitHub Pages repository, replacing the current site files. Do not upload the separate Student Experience ZIP yet; it will be integrated after this SEO foundation.
