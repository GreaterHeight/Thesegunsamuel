# v1.7.2 — Global Contrast + Course Commerce Fix

## Fixed
1. Learning Outcomes text inside white outcome cards was inheriting the dark-section paragraph colour. It is now explicitly dark/readable.
2. Course detail Add to Cart links now carry product data and are handled by the shared commerce script.
3. Course-list and course-detail commerce now use one storage key: `segun_cart`.
4. Cart rendering normalizes the same product shape used by course listings.
5. Enrollment card hover now explicitly makes the ₦ price and supporting text readable against the wine background.
6. Curriculum modules retain correct contrast on both light and dark sections.
7. Muted dark-section text is strengthened for readability.

## Architecture
The fix is global wherever possible. It does not require per-page colour overrides for the three reported defects.
