## Casing

All header and footer labels are explicitly uppercase and also protected by CSS `text-transform: uppercase`.

## Implementation

All pages use:
- `assets/js/global-nav.js`
- the `.ss-global-header` shell
- the `.ss-global-footer` shell
- shared shell CSS in `assets/css/styles.css`

The page body/content is not rebuilt or removed; only the global shell was normalised.
