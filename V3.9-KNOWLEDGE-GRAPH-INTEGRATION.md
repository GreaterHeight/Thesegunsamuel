# v3.9 Knowledge Graph Data Integration

This build adds the canonical Knowledge Graph data layer to the production v3.3.8.1 baseline.

## Source of truth
Master Knowledge & IP Registry v1.3.

## Schema
Knowledge Graph Schema v1.4.

## Data
- `/data/knowledge-graph.json` — canonical graph data
- `/explore/data/knowledge-graph.json` — Explore/Knowledge Graph UI payload

## UI
The Knowledge Graph page now reads the canonical graph payload rather than the older `knowledge-index.json` list.

## Relationships
Only controlled Schema v1.4 relationship types are used.

## Important boundary
The build does not merge unresolved items such as PLAN ↔ The Prepared Mind Method™ or Five-Stage Intelligence Architecture ↔ Strategic Foresight–Architecture Framework.

## Preserved
- Existing global shell
- Approved footer
- Courses experience
- Course-detail layout
- Existing HTML/CSS/JS architecture

v3.9 — Knowledge Graph Data Integration
