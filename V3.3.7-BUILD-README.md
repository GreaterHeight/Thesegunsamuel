# SegunSamuel v3.3.7 — Full Course Detail Consolidated Build

This build is a complete-site replacement generated from the supplied v3.3.5 site archive.

## Scope

All 16 course-detail pages were rebuilt together so that the course-detail architecture and media behaviour remain consistent.

## Canonical course-detail order

Curriculum → Course Details → Requirements → Hosted By → Testimonial → Frequently Asked Questions → Related Knowledge → Knowledge Graph → Applied Case → Enrollment

## Testimonial media behaviour

Priority is:

1. Video available → video is shown.
2. Image available and video unavailable → image is shown.
3. Neither available → branded gradient placeholder is shown.

If both video and image are available, the image automatically becomes the video poster.

No broken image element is placed in the page before media availability is established.

## Media folders

Add future testimonial assets here:

- `assets/images/testimonials/<course-slug>.jpg`
- `assets/videos/testimonials/<course-slug>.mp4`

No course HTML changes are required when these files are added.

## Related Knowledge vs Knowledge Graph

Related Knowledge is the curated learner-facing navigation layer:
Frameworks, Ideas & Articles, Masterclasses, Learning Paths, Case Studies, Application, Podcast and Related Courses.

Knowledge Graph remains the structural ecosystem connection layer.
