How to use it

Observe → Interpret → Design → Apply → Review

Use the framework as a thinking instrument. It should sharpen judgment and application rather than replace contextual judgment.

01 — Observe

Start with what can actually be seen, measured, experienced or evidenced.

02 — Interpret

Identify relationships, assumptions, incentives, patterns and possible meanings.

03 — Design

Choose an intentional response, architecture, strategy or experiment.

04 — Apply

Put the thinking into a real situation and create evidence of capability.

05 — Review

Capture feedback, revise assumptions and strengthen the framework through application.
