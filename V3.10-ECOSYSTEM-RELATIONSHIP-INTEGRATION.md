# v3.10 — Ecosystem Relationship Integration

## Purpose

Connect existing ecosystem entities to the canonical Knowledge Graph without
creating a second taxonomy or inventing relationships.

## Current graph

- Entities: 62
- Relationships: 138
- Entity types indexed: 23
- Course detail pages with Related Knowledge integration hook: 16

## Data

- `/data/knowledge-graph.json`
- `/data/ecosystem-index.json`
- `/js/ecosystem-relationships.js`

## Architecture

Course / Framework / Article / Learning Path / Masterclass / Podcast /
Case Study / Application
→ canonical entity
→ canonical relationship
→ Knowledge Graph

Related Knowledge remains the curated discovery surface.
Knowledge Graph remains the structural relationship surface.

## Constraint

Only existing canonical entities and explicit fields (`parent_id`,
`source_id`, `related_ids`) were used. No new semantic relationships were
invented during this build.
